# 💸 WhatsApp Expense Logger

A smart expense tracking tool that integrates OCR, Twilio API, and Cloudflare Tunnel — perfect for logging expenses through WhatsApp and analyzing spending habits in real-time.

## 🔧 Features

- 💬 Message-based expense logging via WhatsApp
- 🧠 OCR for automatic text extraction from receipts
- 🔄 Real-time webhook updates using Twilio Sandbox
- 🌐 Public server exposure with Cloudflare Tunnel

## 🚀 Tech Stack

- Python, Flask
- Twilio API
- pytesseract (OCR)
- Cloudflare Tunnel
